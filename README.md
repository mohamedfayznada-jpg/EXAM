# EXAM — Student Assessment Web App

A lightweight MVP for creating and taking student assessments.

## Current MVP
- Student entry flow
- Exam catalog
- Timed exams
- Multiple-choice questions
- Automatic scoring
- Pass/fail evaluation
- Local attempt history
- Admin dashboard
- Average score and pass rate
- Responsive UI
- LocalStorage persistence for demo use

## Run
Open `index.html` in a browser.
